# Website editing handoff

This site is prepared for Pages CMS. All routine content lives in `content/*.json`, and `.pages.yml` turns those files into friendly editing forms.

## One-time owner setup

1. Create a GitHub account owned by the Hancock County Republican Committee.
2. Put this project in a repository owned by that account.
3. Visit https://app.pagescms.org and sign in.
4. Install the Pages CMS GitHub App only for this repository.
5. Open the repository in Pages CMS and invite approved editors.
6. Connect the repository to the chosen host so every saved edit automatically republishes the site.

## Before public launch

- Replace every placeholder in the Pages CMS editor.
- Upload the approved logo and photographs.
- Confirm the committee's paid-for-by disclaimer.
- Connect the contact and volunteer forms to an inbox or form service.
- Confirm candidate claims, links, offices, and current active status.
- Turn on two-factor authentication for every owner and editor.

Do not share one password. Give each editor an individual account and remove access when it is no longer needed.
